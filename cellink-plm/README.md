# CELLINK PLM

이차전지 설비 제작·납품 업체를 위한 한국어 PLM 체험 사이트.

## 실행

`dist`를 정적 웹 서버로 열면 됩니다. 빌드나 설치가 필요하지 않습니다.

```powershell
python -m http.server 4173 --directory dist
```

## 기능

- ChatGPT 사이트 로그인 진입, 이름·화면 모드 선택 체험
- 관리용 통합 현황, 프로젝트 등록·수정, 내수·수출 구분
- Frappe Gantt 기반 일정 차트, 작업 등록·수정, 선행 작업 연결, 진행률·지연 계산
- 큰 글씨·버튼을 사용하는 현장용 내 작업 화면
- 이슈 등록·수정·상태 변경, 담당자·분류·상태 필터, 목록·보드
- 표준 Excel/CSV 다중 파일 가져오기, 검증·미리보기, 양식 다운로드
- 데이터 기반 주간 초안 생성·편집·저장, Excel 출력, 인쇄/PDF
- 문서 등록·개정 이력·첨부파일 다운로드, 부품 구성, 설계 변경 검토 흐름
- 브라우저 저장, JSON 백업·복원

## 범위와 한계

가상 데이터 기반의 프런트엔드 체험 버전입니다. 데이터와 파일은 같은 브라우저의 localStorage에 저장되며 여러 직원 사이에 공유되지 않습니다. 이름 입력은 인증이 아니며 화면 모드 선택은 권한을 부여하지 않습니다. 호스팅 접근은 Sites의 ChatGPT 인증 및 비공개 접근 제어가 담당합니다. 사내 계정·역할 기반 권한, 서버 데이터베이스·파일 저장, 실제 AI API는 아직 연결하지 않았습니다. 메모 추출은 표시된 키워드 규칙을 사용합니다. 주간 요약은 현재 데이터의 결정적 계산 결과이며 AI 호출이 없습니다. 개정 시 이전 문서의 메타데이터를 보관하며 첨부파일은 최신 파일만 유지합니다.

등록 작업의 진행률 단순 평균을 프로젝트 진척으로 사용합니다. `종료일 < 오늘`이고 `진행률 < 100`인 작업이 지연입니다. 선행 작업은 표시용이며 일정 자동 재계획을 하지 않습니다. 과거 시점의 진척 스냅샷은 없고 주간 신규·해결 이슈 날짜와 현재 지연 현황을 구분해 표시합니다.

## 참고 자료

작업 공간의 B1 제조장비 프로젝트 일정·이슈 통합관리 제안서 전체와 업무용 AI 서비스 개발 프로젝트 가이드 27–28페이지를 바탕으로 구성했습니다.
